# R1zzz_Al-Qur'an - Platform Al-Qur'an Digital Modern

Aplikasi web Al-Qur'an Digital responsif berbasis **Single Page Application (SPA)** yang dibangun dengan **HTML5, CSS3, dan JavaScript Vanilla**.

## 🚀 Fitur Utama
- **114 Surah & Daftar Juz**: Navigasi lengkap dengan audio murottal dan tafsir Kemenag.
- **10 Qari Internasional**: Pilihan suara qari berkualitas tinggi.
- **Terjemahan Per Kata**: Membantu memahami makna harfiah ayat.
- **Catatan & Refleksi Pribadi**: Menyimpan catatan ayat penting langsung di browser.
- **50 Doa Harian**: Kumpulan doa pilihan lengkap Arab dan artinya.
- **Mode Gelap / Terang**: Kenyamanan visual maksimal.

## 💻 Cara Hosting ke GitHub Pages
1. Pastikan seluruh file di atas berada langsung di direktori utama (*root*) repository GitHub Anda.
2. Masuk ke menu **Settings** > **Pages** di repository Anda.
3. Pada bagian **Branch**, pilih `main` dan foldernya `/ (root)`, lalu klik **Save**.
4. Website Anda siap diakses secara online!
