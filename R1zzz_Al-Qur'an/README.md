# R1zzz_Al-Qur'an - Platform Al-Qur'an Digital Modern

Aplikasi web Al-Qur'an Digital responsif berbasis **Single Page Application (SPA)** yang dibangun dengan **HTML5, CSS3, dan JavaScript Vanilla**.

## 🚀 Fitur Utama
- **114 Surah & 30 Juz Complete**: Seluruh surah dapat diakses dengan audio murottal & tafsir Kemenag.
- **50 Doa Harian**: Kumpulan amalan doa sehari-hari lengkap dengan teks Arab dan artinya.
- **Auto-Play Murottal**: Pemutaran otomatis ayat berurutan disertai animasi scroll otomatis.
- **Bookmark & Last Read**: Menyimpan posisi bacaan terakhir dan ayat favorit ke `LocalStorage`.
- **Mode Gelap / Terang**: Pergantian tema visual yang nyaman di mata.

## 💻 Cara Menjalankan
1. Buka folder `R1zzz_Al-Quran` di VS Code.
2. Klik kanan file `index.html` -> **Open with Live Server**.
